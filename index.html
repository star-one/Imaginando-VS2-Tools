Imaginando VS2 / Visual Synthesizer

Shaders and tools
for VS2

23 shader Materials for the VJ software VS2, each with a plain version and an audio-reactive version that moves with the music. And two tools that turn your own SVG drawings, and shaders from Shadertoy, into Materials of your own.

SVG to Material Shadertoy to Material Source on GitHub

What this is

VS2 lets you write your own visuals as small GLSL programs called Materials. This project is a collection of them, and the tools to make more.

23 Materials

Tunnels, fractals, vapourwave scenes, and visuals for noise music. Every one has knobs that follow the same order, so a controller keeps its mappings from one Material to the next.

Plain and audio-reactive

Each Material comes in two versions. The audio-reactive one listens to VS2's spectrum and moves the picture with bass, mids and highs, with the frequency ranges set in Hz.

Two converters

Paste an SVG or a Shadertoy shader, choose what each knob controls, preview it live, and download a ready-to-use Material. They run in your browser, and nothing is uploaded.

Using one in VS2

  1. Download a .frag file from the project on GitHub, or make one with a converter.
  2. In VS2's Material Editor, create a new shader Material and paste the code in (or import the file). The comment at the top of the file names the knobs.
  3. For an audio-reactive Material, set the audio source on the Layer. The project README explains the settings, and how to check the frequency layout against your copy of VS2.
  4. Adjust the constants at the top of a file to taste: the speed, the frequency bands, and the strength of each reaction are all there.
A note on flashing. The noise-music Materials, and the audio-reactive versions in general, flash and change suddenly, on purpose. Please warn audiences who may include people with photosensitive epilepsy.
